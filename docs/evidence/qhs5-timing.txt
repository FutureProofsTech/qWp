Optimization:
The 512-bit mode precomputes each derive-key context once and reuses it for
every chain, leaf, node, message, and checksum hash. This is byte-identical to
the one-shot construction: the same context key and the same `0x00`/`0x01`
half tags are used. The QHS-5 KAT hash is unchanged. Measured improvement over
the one-shot implementation: keygen ≈35%, cached sign ≈29%, verify ≈34%.
