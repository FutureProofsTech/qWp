# qWp Math Specification (Phase 0)

**Status:** Frozen for the invariant and bounds; production signatures are QHS-1/2/3/3.1/4 (ADR-0002–0006).

**Authority:** This document plus `docs/05-qhs1.md` and `docs/gap-register.md`. No external standard is authoritative.

---

## 1. Conventions

- Braid group \(B_n\) on \(n=8\) strands, generated by \(\sigma_1,\dots,\sigma_7\).
- A braid word is a finite sequence over \(\{\pm1,\dots,\pm7\}\).
- A positive integer \(+i\) is \(\sigma_i\); a negative integer \(-i\) is \(\sigma_i^{-1}\).
- The closure \(\hat{\beta}\) is the link obtained by connecting the top and bottom of the braid.
- The number of link components is the number of cycles of the permutation induced by the braid.
- The writhe is \(w(\beta)=\sum \epsilon_i\), where \(\epsilon_i=+1\) for \(\sigma_i\) and \(-1\) for \(\sigma_i^{-1}\).

## 2. Invariant definition (C2 closed)

qWp uses the **conventional Kauffman bracket and Jones polynomial**. The word "conventional" means the mathematical definition, not an external standards authority.

### 2.1 Kauffman bracket

\[
\langle \varnothing \rangle = 1,
\]

\[
\langle L \sqcup \bigcirc \rangle = (-A^2 - A^{-2})\langle L \rangle,
\]

\[
\langle L \rangle = A\langle L_0 \rangle + A^{-1}\langle L_\infty \rangle.
\]

Here \(L_0\) and \(L_\infty\) are the two smoothings at a chosen crossing.

### 2.2 Jones polynomial

\[
V_L(t) = (-A^3)^{-w(L)} \langle L \rangle \Big|_{t=A^{-4}}.
\]

Equivalently, the conventional skein relation is

\[
t^{-1} V(L_+) - t V(L_-) = (t^{1/2} - t^{-1/2}) V(L_0).
\]

For an \(m\)-component unlink,

\[
V = (-t^{1/2} - t^{-1/2})^{m-1}.
\]

For a knot, \(V \in \mathbb{Z}[t^{\pm1}]\). For a link, half-integer exponents may occur; qWp stores the invariant in a degree-shifted integer array after clearing the half-integer factor.

### 2.3 Rejected recurrence

The project document's recurrence

\[
V(L_+) = t^2 V(L_0) + t^3 V(L_-)
\]

is **not** the conventional Jones skein relation. It is rejected. It does not specify writhe/orientation, does not handle disjoint unlinks, and has not been shown invariant under Reidemeister moves.

### 2.4 Invariance

The Kauffman bracket is invariant under Reidemeister II and III. Reidemeister I changes the bracket by a factor of \(-A^{\pm3}\); the writhe normalization cancels it. Therefore \(V_L(t)\) is a link invariant. The implementation must validate this with:

- KATs: unknot, trefoil, figure-eight, Hopf link, 2-component unlink;
- RII/RIII property tests on random braids;
- differential tests against the in-tree naive reference;
- optional Sage/KnotTheory cross-check.

A full formal proof is the standard bracket-invariance argument; the qWp proof obligation is to show the implementation computes exactly that state sum and normalization.

## 3. Degree bounds (C3 closed)

For \(n=8\) and \(c\) crossings:

- Each state contributes an \(A\)-degree between \(-c\) and \(c\).
- A state has at most \(l\le n\) loops; each loop factor \(\delta=-A^2-A^{-2}\) contributes at most \(\pm2(l-1)\).
- Therefore the bracket degree is bounded by
  \[
  [-c-2(n-1),\; c+2(n-1)].
  \]
- The writhe \(w\in[-c,c]\) shifts the \(A\)-degree by \(-3w\).
- With \(t=A^{-4}\), the \(t\)-degree is bounded by
  \[
  |\deg_t V| \le c + \frac{n-1}{2}.
  \]

For \(n=8\):

| Crossings \(c\) | Bracket \(A\)-degree | Jones \(t\)-degree | Coefficients needed | qWp buffer |
|---:|---|---:|---:|---|
| 32 | \([-46,46]\) | \(\pm35.5\) | 72 (half-integer) / 73 | 129 (`-64..=64`) |
| 96 | \([-110,110]\) | \(\pm99.5\) | 200 / 201 | 257 (`-128..=128`) |
| 144 | \([-158,158]\) | \(\pm147.5\) | 296 / 297 | 385 (`-192..=192`) |

The 516-byte public key (129 `i32`, degrees `-64..=64`) is sufficient for the **32-crossing private key**. The signature product may reach 96 crossings (private 32 + message 32 + inverse 32), so the verifier uses a 257-coefficient `i64` scratch buffer. A 144-crossing worst case uses a 385-coefficient scratch buffer.

## 4. Coefficient bounds and overflow

A crude term bound is:

\[
2^c \cdot 2^{n-1} = 2^{c+n-1}.
\]

For \(c=32,n=8\), this is \(2^{39}\), which exceeds `i32`. This is a **worst-case term count**, not a proof that a coefficient reaches it, but it is enough to reject the assumption that `i32` is always safe.

qWp rules:

1. Accumulate in `i64` (or `i128` if a tighter proof requires it).
2. Convert to `i32` only after a checked range test.
3. The keygen predicate rejects any braid whose final public polynomial has a coefficient outside `i32`.
4. The verifier rejects any public key/signature computation that would overflow.
5. The rejection rate is measured in Test 1; if it is non-negligible, the public-key format must grow (format version change), not silently saturate.

This closes the *format* gap. The *distribution* impact remains a keygen test obligation.

## 5. Temperley–Lieb solver

### 5.1 Basis

For \(n=8\), the Temperley–Lieb algebra \(TL_8\) has

\[
C_8 = \frac{1}{9}\binom{16}{8} = 1430
\]

planar matching states. Each state is a pairing of 8 top and 8 bottom points.

### 5.2 Crossing update

A crossing \(\sigma_i\) acts as

\[
\sigma_i \mapsto A\cdot 1 + A^{-1} e_i
\]

(or the inverse assignment for \(\sigma_i^{-1}\)), where \(e_i\) is the cup-cap element at position \(i\). The loop relation is

\[
e_i^2 = \delta e_i,\qquad \delta=-A^2-A^{-2}.
\]

### 5.3 Closure and degree sweep

After all crossings, close the diagram. Each closed loop contributes \(\delta\). The result is a Laurent polynomial in \(A\); substitute \(A=t^{-1/4}\) and normalize by writhe.

Implementation strategy:

- fixed 1430-state array;
- process one target degree at a time (degree sweep) to keep memory small;
- fixed loops, no recursion;
- `i64` coefficients;
- explicit stack/state machine with a proven bound.

Complexity per degree is \(O(c\cdot 1430)\). For \(c=32\), 129 degrees: about 5.9M coefficient operations. For \(c=96\), 257 degrees: about 35M. For \(c=144\), 385 degrees: about 79M. This is practical; the naive \(2^c\) tree is not.

## 6. Reduction and canonicalization

The wire format carries a braid word. The verifier reduces it before use.

Pipeline:

1. Validate generators and length.
2. RII inverse annihilation.
3. Far commutativity to expose inverse pairs.
4. RIII with a deterministic terminating orientation.
5. Garside left normal form for canonicalization (simple elements are permutations; \(8! = 40320\)).
6. Metrics: reduced length, exponent sum, permutation cycles, distinct generators.

The signature stores a raw braid word with a length byte. The verifier re-reduces; semantic equivalence is accepted, byte-level malleability is documented. If byte-level uniqueness is required, store the Garside normal form instead; the 160-byte container is large enough for the 96-crossing case only if the normal form fits, which must be measured.

## 7. Hash-to-braid

1. `BLAKE3::derive_key("qWp v1 message braid", message)` → 32 bytes.
2. Interpret as a 256-bit little-endian integer.
3. Reduce modulo \(14^{32}\) (bias \(2^{-134}\), negligible).
4. Extract 32 base-14 digits.
5. Map `0..6` → `+1..+7`; `7..13` → `-1..-7`.

The signature also binds the full 32-byte message digest (decision D16). The 32-crossing message braid is a topological mixing component, not the sole message commitment. A braid collision is not a forgery because the verifier checks the full digest.

## 8. Signature construction (C1 decision)

### 8.1 Original construction is rejected

The original signature is

\[
S = P \cdot M \cdot P^{-1}.
\]

For any braid \(P\),

\[
\widehat{P M P^{-1}} \cong \widehat{M},
\]

so every link invariant, including \(V\), satisfies \(V(\widehat{S})=V(\widehat{M})\). The private key cancels. \(S=M\) is a universal forgery. This is a proof, not a heuristic.

### 8.2 What a sound construction needs

A sound qWp signature must:

1. bind a secret that cannot be cancelled by conjugation;
2. have a verification equation that actually checks that secret;
3. fit the 160-byte signature and 516-byte public key, or explicitly change the formats;
4. survive the internal attack suite;
5. publish a measured attack cost, not a standard-compliance claim.

### 8.3 Candidate analysis

**Braid signature schemes (topological).** Published braid signature schemes use \(B_n\) with \(n\approx20\)–28 and signatures around 1.6–2.6 kbit (about 207–331 bytes) at rough security levels \(2^{20}\)–\(2^{30}\). qWp's \(B_8\), 32 crossings, and 160-byte signature are substantially smaller. No known braid signature construction meets 128-bit security at these parameters.

**Hash-based one-time signatures.** A 160-byte signature gives at most roughly 64–80-bit security with practical Winternitz parameters; it does not meet a 128-bit target.

**Compact custom group signature.** A custom Schnorr-like signature over a 256-bit prime-order group can fit 32-byte public keys and 64–96-byte signatures. It is non-standard if the group is qWp-defined, but it abandons the topological invariant and requires a new in-tree group implementation.

**Matrix-group signature.** A 2×2 matrix group over a 128-bit field gives roughly 64-bit generic security and a signature larger than 160 bytes; a 256-bit field gives better security but a signature around 288 bytes. It does not fit.

### 8.4 Decision

The original topological signature cannot be made sound within the 160-byte/128-bit target. Phase 0 closes C1 as a **rejected construction**.

The first production path is **QHS-1** (ADR-0002): a custom WOTS/Merkle hash-based signature on in-tree BLAKE3, 2408-byte signatures, 64-byte keys, with a written EUF-CMA proof in `docs/05-qhs1.md`. QHS-2, QHS-3, QHS-3.1, and QHS-4 extend the same hash-based paradigm with their own ADRs, proofs, and formats (`docs/07-qhs2.md`, `docs/10-qhs3.md`, `docs/12-qhs31.md`, `docs/13-qhs4.md`). The braid/Jones engine remains a research module; it is not part of the production security argument.

No standard fallback is permitted.

## 9. Security model

- Signature game: EUF-CMA.
- Key recovery: measured best-known attack cost.
- Adversary: remote, local timing, fault, chosen message, quantum (measured, not assumed).
- Assumptions: BLAKE3 collision/preimage resistance; the chosen hard problem of the replacement signature; entropy quality.
- Claims: measured and reproducible; no NIST/ISO/FIPS/RFC compliance claim.
