## 1. Review scope

- WOTS one-time unforgeability with base-64 digits and 63-step chains.
- Checksum decrease with 43 message digits and 2 checksum digits.
- Merkle tree unforgeability over 4,096 leaves (height 12).
- Stateful leaf invariant.
- Domain separation between QHS-1, QHS-2, QHS-3, and QHS-3.1.
- Code-to-spec mapping.
- Parser/bounds proofs.
- Attack-suite coverage.
- Slice-based leaf handling and parallel-keygen equivalence.

## 2. Assumptions accepted

1. BLAKE3 is preimage-resistant and collision-resistant for the fixed contexts.
2. BLAKE3 derive-key is a PRF for secret derivation.
3. The signer never reuses a leaf and never rolls back the counter.
4. The seed is generated by a CSPRNG (production keygen).
5. The signature checksum is integrity-only; authentication comes from WOTS + Merkle.
6. The public-leaf cache is untrusted data. Its fingerprint and keyed MAC reject corruption; even a forged cache cannot yield a valid signature because the verifier recomputes the Merkle root.
